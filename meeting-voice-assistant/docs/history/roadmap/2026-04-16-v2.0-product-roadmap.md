## 1. 产品愿景

**愿景**: 将会议语音助手从单一会议场景扩展为**智能会议与个人面试助手双场景平台**，会议助手服务企业团队，面试助手服务个人应聘者，通过 AI 驱动的知识管理和实时分析，成为用户面试求职的核心帮手。

**北极星指标**: 用户每周使用频次从 V1 的 1.2 次提升至 3 次以上；面试助手用户面试准备满意度 > 4/5；面试进度掌握感评分 > 4/5。

## 3. V2.0 目标场景

### 3.1 会议助手场景 (Meeting Assistant)

**目标用户**: 企业内部会议、跨团队沟通、项目 Stand-up

**核心价值**:
- 实时转写，让与会者专注讨论而非笔记
- 自动生成会议摘要和行动项
- 会议内容自动入库，形成团队知识库
- 说话人识别，追踪发言归属

**关键指标**:
- 会议记录完整率 > 95%
- 摘要生成满意度 > 4/5
- 行动项追踪完成率 > 60%

### 3.2 面试助手场景 (Interview Assistant)

**目标用户**: 个人应聘者（求职者）

**核心价值**:
- 面试进度可视化：不同招聘岗位的投递进展、岗位匹配度、能力维度评估
- 面试前：生成模拟面试题，通过模拟对答生成面试评价
- 面试中：实时语音识别 + **答案提示**（实时给应聘者提供回答建议）
- 面试后：根据面试语音进行全量复盘，生成学习计划表

**关键指标**:
- 转写准确率 > 98%
- 答案提示响应时间 < 2 秒
- 用户面试进度掌握感评分 > 4/5
- 学习计划完成率 > 60%

## 4. V2.0 功能路线图

### 4.1 Now (Q2 2026) — 核心架构与认证

#### Initiative 1: 用户认证系统
**问题**: 当前无用户体系，无法实现数据隔离和个性化
**解决方案**: 实现 JWT 认证，支持注册/登录/Token 刷新
**成功指标**: 认证系统上线 2 周内，DAU 认证率 > 80%

| 功能点 | 负责人 | 状态 |
|--------|--------|------|
| 后端 JWT 认证模块 | backend-dev | 待分配 |
| 用户注册/登录 API | backend-dev | 待分配 |
| WebSocket 认证集成 | backend-dev | 待分配 |
| 前端 Auth Store | frontend-dev | 待分配 |
| 登录/注册 UI | frontend-dev | 待分配 |

#### Initiative 2: 数据模型重构
**问题**: 现有数据模型不支持多用户、跨会话关联
**解决方案**: 重新设计数据模型，支持用户、项目、会议、面试实体

| 功能点 | 负责人 | 状态 |
|--------|--------|------|
| 用户数据模型 | backend-dev | 待分配 |
| 会议/面试会话模型 | backend-dev | 待分配 |
| 知识条目关联模型 | backend-dev | 待分配 |

---

### 4.2 Next (Q3 2026) — 面试场景与知识增强

#### Initiative 3: 面试助手功能（面向个人应聘者）
**问题**: 应聘者缺乏专业工具把握面试进度、提升面试表现
**解决方案**: 新增面试场景模式，支持面试全流程管理

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 面试进度管理 | P0 | 投递进展可视化、岗位匹配度、能力维度评估 |
| 答案提示 | P0 | 面试中实时语音识别 + 回答建议 |
| 面试模拟 | P0 | 生成模拟面试题，模拟对答生成评价 |
| 面试复盘 | P0 | 面试后全量复盘，生成学习计划 |
| 多轮面试关联 | P1 | 同一岗位多次面试记录关联展示 |
| 学习计划 | P1 | 基于复盘生成个性化学习计划 |

#### Initiative 4: 知识图谱增强
**问题**: 会议知识孤岛，无法跨会话检索和关联
**解决方案**: 增强 GraphRAG，实现会议间实体关联和智能检索

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 跨会议实体关联 | P1 | 自动识别不同会议中的相同主题/人员 |
| 智能检索增强 | P0 | 基于知识图谱的语义搜索 |
| 知识卡片 | P1 | 自动抽取关键决策、承诺事项 |
| 图谱可视化优化 | P2 | 交互式图谱，筛选、钻取 |

---

### 4.3 Later (Q4 2026) — 协作与移动端

#### Initiative 5: 团队协作功能
**问题**: 会议记录仅创建者可见，团队知识共享困难
**解决方案**: 团队空间、共享会议库、权限管理

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 团队空间 | P2 | 团队共享会议库 |
| 会议分享 | P2 | 生成分享链接，设置查看/编辑权限 |
| 评论与标注 | P2 | 在会议记录中添加评论 |
| @提及 | P2 | 通知相关人员 |

#### Initiative 6: 移动端支持
**问题**: 移动场景（现场面试、户外会议）无法使用
**解决方案**: PWA 适配，支持 iOS/Android

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| PWA 支持 | P2 | Service Worker、离线缓存 |
| 移动端 UI 适配 | P2 | 响应式布局 |
| 推送通知 | P3 | 会议提醒、@提及通知 |
