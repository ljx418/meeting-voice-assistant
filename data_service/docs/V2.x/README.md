审计时建议按以下顺序阅读：

1. 先读 PRD，确认产品目标和用户体验。
2. 再读目标架构，确认组件边界和安全原则。
3. 再读开发及验收计划、里程碑、E2E 矩阵。
4. 最后打开 drawio，审查当前差异、目标架构、开发验收、里程碑和出门条件是否一致。
