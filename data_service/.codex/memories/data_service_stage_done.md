# data_service Stage Completion Rule

For the `data_service` project, after completing each development phase:

- Update related test files and acceptance cases.
- Update architecture diagrams.
- Always include `docs/data_service/current_vs_target_flow.drawio` in the documentation update scope when completing a phase or acceptance/documentation sync; it remains the fastest visual status document.
- Explicitly show the difference between the current architecture diagram and the target architecture diagram.
- Treat this as part of the phase completion definition, especially when MCP, agent workflow, ingest/query, quality governance, GraphRAG, or llmwiki architecture changes.
