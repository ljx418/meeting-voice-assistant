# ResearchNotebook V1.7 Design Index

日期：2026-05-30

## 阶段目标

V1.7 聚焦 PRD MVP 的普通用户体验重组，不新增后端能力。目标是把 V1.6 已验收的受限能力整理成 NotebookLM-style 三列工作流：

- 来源
- 资料导读与问答
- 输出

## 当前声明边界

V1.7 只能声明 PRD MVP 受限路径的 UX 改善。仍不能声明：

- OCR ready
- Audio Overview ready
- PPT generation ready
- Mindmap ready
- Document comparison ready
- all websites URL ready
- all-source-type ready
- cloud sync / collaboration ready
- arbitrary Agent tool execution ready
