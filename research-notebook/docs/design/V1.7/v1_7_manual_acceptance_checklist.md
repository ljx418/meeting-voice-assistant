# ResearchNotebook V1.7 Manual Acceptance Checklist

日期：2026-05-30

## 手工验收最小步骤

1. 打开 ResearchNotebook。
2. 创建 Notebook。
3. 一次导入数字人 Markdown 和 PDF。
4. 等待来源完成处理。
5. 确认页面显示三列：来源、资料导读与问答、输出。
6. 确认资料导读显示概览、关键主题和建议追问。
7. 点击一个建议追问。
8. 确认问答区有加载反馈并返回回答。
9. 点击回答引用。
10. 确认来源抽屉打开并显示原文片段。
11. 生成笔记、学习导读、资料简报、常见问题。
12. 下载 Markdown 和 JSON。
13. 提问资料外问题，确认拒答和补源建议。
14. 确认音频概览、PPT、思维导图、文档对比均为暂不可用。
15. 窄屏查看无明显重叠。
16. 归档 Notebook。

## 通过标准

- 主界面没有明显开发阶段文字。
- 用户不需要理解 source_id / unit_id / evidence_id。
- 引用可点击定位。
- 输出内容带引用。
- 暂不可用能力不会生成伪输出。
- 无明显区块重叠。
