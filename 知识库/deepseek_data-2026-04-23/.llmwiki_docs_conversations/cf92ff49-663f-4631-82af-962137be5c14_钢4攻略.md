### 🚀 第一阶段：奠基与扩军 (1936-1938)

这三年是默默积累、打好地基的关键时期。你的目标是扩充工业、储备资源，并组建起一支高质量的种子部队。

-   **国家焦点**：
    -   **1936年**：优先点出 **【莱茵兰】**（获取政治点数和稳定度），随后直奔 **【四年计划】** 和 **【捷克斯洛伐克】**。吞并捷克是早期最大的一次性工业爆发，至关重要。
    -   **1937年**：处理奥地利（【德奥合并】），之后可以将焦点转向 **【陆军创新】** 或 **【空军创新】** 的科研加成线，为后续节省科研时间。
-   **科学研究**：
    -   **工业**：**电子机械工程、建筑技术、集中工业** 是永远的第一优先级。
    -   **陆军**：研究关键的 **【中型坦克I】**（三号坦克），以及步兵必须的 **【支援武器I】** 和 **【火炮I】**。
    -   **学说**：尽早开始研究 **【闪电战学说】**，这是你后期机动作战的灵魂。
-   **军队建设**：
    -   **主力步兵师**：构建25宽度的师，如9步3炮1工兵支援连。这是你战线上的中流砥柱，能抗能打 [citation:1]。
    -   **先锋装甲师**：组建一个核心的6营三号坦克+2营四号坦克的混合师。四号坦克提供关键的“硬度”，让师更耐揍 [citation:1]。
-   **工厂建设**：**全民用工厂**。只有先修好了“家”，未来才能更快地造“枪”。所有政治点数优先用于任命工业顾问，如 **【赫尔曼·戈林】** 来加速建设。

### ⚙️ 第二阶段：战备冲刺 (1939-1941.6)

战争临近，节奏必须加快。从39年9月入侵波兰开始，你的工业引擎需要全速运转。

-   **国家焦点**：
    -   **1939年**：傀儡 **【波兰】** 是极佳选择，能大幅缩减未来对苏战线的长度 [citation:1]。之后点出 **【莫洛托夫-里宾特洛甫条约】**，获取苏联的廉价资源 [citation:1]。
    -   **1940-41年**：完成对法、比、荷的低地国家征服后，焦点转向 **【帝国总动员】**，在开战前就获得动员加成 [citation:1]。
-   **科学研究**：
    -   **陆军**：全力冲刺 **【中型坦克III】（豹式）**！这是你横扫苏联装甲部队的王牌。
    -   **空军**：研究并换代至 **【Fw-190系列战斗机】**，其高攻防属性将帮你夺取绝对制空权 [citation:3]。
    -   **后勤**：研究 **【机械化】** 和 **【卡车】** 的改进型号，提升装甲师的补给速度和油料容量 [citation:4]。
-   **工厂建设**：**从1938年底开始，将所有建设槽位切换为军工和必要的资源设施（如炼油厂）**。同时，务必开始建设 **【发电厂】**，以避免后期严重的电力惩罚 [citation:4]。

### 🛠️ 1941年最优装备设计

战前，确保你的工厂正在生产以下主力装备。黑冰的装备设计充满细节，这里给出最稳妥的设计思路：

-   **坦克（1941年标准）**
    -   **主力**：**豹式坦克**。设计核心应围绕 **【长身管75mm主炮】**、**【倾斜装甲】** 和 **【强化引擎】**。目标是软攻、穿甲和速度的平衡。
    -   **辅助**：**四号坦克**。可以转型为 **【四号坦克歼击车】** 或 **【四号自行火炮】**，为装甲师提供廉价的反坦克和火力支援。
    -   *注意：黑冰中三号坦克在豹式成型后即可退居二线，不必强求生产昂贵的虎式 [citation:1]。*
-   **飞机（1941年标准）**
    -   **制空权**：**Fw-190A**。装甲和火力突出，是争夺制空权的利器 [citation:3]。
    -   **对地支援**：**Me-410** 或升级后的 **Ju-87D（斯图卡）**。确保它们有足够的航程，能覆盖苏联西部的关键战场。
-   **舰船**
    -   **潜艇**：**VII型潜艇**。不断改进其水下续航、鱼雷和引擎隐蔽性。
    -   **水面舰艇**：集中资源完成 **【俾斯麦级】** 和 **【沙恩霍斯特级】**，组成精悍的破交舰队，不要试图与英国皇家海军进行主力决战 [citation:3]。

### 🎖️ 军队编制与学说

-   **主力步兵师**：**9步兵营 + 3火炮营 + 工兵连 + 反坦克连**。这是经过实战检验的“万能师”，防御力强，配合少量反坦克炮足以应对苏联的T-34浪潮 [citation:1]。
-   **装甲师（王牌）**：**6中坦营 + 2中坦歼击营 + 2机械化步兵营 + 工兵连 + 后勤连 + 侦察连**。这个配置兼顾了突破、反装甲和持续作战能力 [citation:1]。
-   **学说**：**优势火力学说**（右线）或 **机动作战学说**。黑冰里防御优势巨大，前期利用优势火力学说的加成在防线上消耗苏军，待豹式坦克形成规模后，再切换为机动作战学说的闪电战进行大纵深包围。

### 🏭 关键工厂建设顺序 (截至1941年中)

1.  **1936-1938年：全民用**。目标是在吞并奥地利和捷克前，将本土基础民工数量最大化。
2.  **1939年初：转型**。开始混搭建设少量军工，保证入侵波兰时装备充足。
3.  **1940年夏（法国陷落后）：军工爆发**。利用从西欧掠夺的工厂和资源，将所有空余槽位全部用于建造军工，并补充1-2个炼油厂和发电厂 [citation:6]。
4.  **1941年初：决战准备**。根据库存情况，微调生产线。如果油料紧张，再补一个合成炼油厂；如果坦克生产线效率低，则用民工改善基础设施或进行贸易。

### 💡 深度提示：黑冰的灵魂

1.  **敬畏稳定度**：黑冰中，低稳定度会直接乘法削弱你的工厂产出，最高可达50% [citation:4]。政治点数要经常用于通过决议提升稳定度。
2.  **理解装备工厂**：坦克、飞机等不再仅仅消耗钢铁，还需要对应的 **【引擎工厂】**、**【炮管工厂】** 等 [citation:4]。建设军工时，要注意这些高级装备工厂的配比。
3.  **粮食即生命**：入侵苏联时，务必关注 **【粮食】** 储备。苏联广袤的领土会导致补给线过长，粮食消耗激增，后勤不足会直接让你的精锐部队失去战斗力 [citation:4]。
4.  **经验获取**：一定要派志愿军和顾问去 **【西班牙内战】** 捞陆军和空军经验，这是你提前修改精锐师模板和设计先进装备的资本 [citation:7]。

最后想提醒你，黑冰的苏联拥有极强的“火星兵”补充能力和各种民族精神buff [citation:2]。因此，1941年的进攻必须目标明确，力求在冬季来临前消灭苏军有生力量，并尽可能向东推进，压缩其战略纵深和工业产能。祝你取得胜利！

### 📅 整体运营时间轴
*   **1936-1938年 奠基期**：全力发展经济，种民用工厂，吞并奥地利和捷克斯洛伐克。
*   **1939年 冲刺期**：切换至军工生产，组建精锐装甲师，准备对波兰开战。
*   **1940年 红利期**：征服法国、低地国家后，利用获得的工业产能，将装备全面升级换代，为进攻苏联做准备。

### 🛤️ 国家焦点顺序
国策的节奏基本是跟着历史事件走，主要目标是最大化获取工业、科研加成和吞并领土[citation:3]。

*   **1936年**：**进军莱茵兰** → **四年计划** → **自给自足**
*   **1937年**：两个加民工和稳定度的国策 → **德奥合并**（第一个工业大礼包） → **索取苏台德**
*   **1938年**：**慕尼黑协定的仲裁** → **捷克斯洛伐克的命运**（第二个工业大礼包） → **东方领土主张**
*   **1939年**：**苏德互不侵犯条约**（获取资源） → **但泽或战争**（开战）
*   **1940-41年**：吞并西欧后，点出 **【大空间经济】** 和 **【整合战时经济】** 来降低消费品，并点亮关键的 **【第五个科研槽】**[citation:3]。

### 🔬 科学研究顺序
科研优先级：**工业 > 装甲 > 支援连 > 学说**。步兵装备和火炮科技可以适当滞后，靠缴获来补充[citation:3][citation:7]。

*   **1936-37年**：开局研究**电子机械工程**、**建筑技术**、**分散工业I**。陆军科技优先研究**轻型坦克II**（二号）和**支援装备I**。利用国策给的加成卡，加速研究关键的 **【中型坦克II】**（三号），尽量在37年底或38年初拿到[citation:3][citation:7]。
*   **1938-39年**：研究**分散工业II/III**，并点亮**维修连**、**后勤连**、**工兵连II**。学说走**闪电战**左线（优势火力也可以，但闪电战更符合德国机动战的需求）[citation:3]。
*   **1940-41年**：全力研究 **【中型坦克III】**（四号/豹式雏形）。飞机方面研究**1940型战斗机**（如Fw-190）。别忘了点出**煤液化**科技，为你的装甲部队储备燃油[citation:3]。

*   **坦克设计（1941年）**：[citation:3]

    *   **炮塔**：**三人炮塔**（可靠性）。
    *   **配件**：**无线电**、**负重轮**（可选，增加可靠性）、**柴油发动机**（省油）。

**2. 主力步兵师（防守填线）**

*   **支援连**：工兵、火炮、防空（可选）[citation:2][citation:3]。

### ⚔️ 如何低代价获取“骷髅师”

| 步骤 | 操作 | 说明 |

### 🏋️ 如何训练部队并切换编制不丢经验

这是钢4里一个非常实用但容易被忽视的技巧。核心原理是：**部队的经验是以“平均经验值”的形式存在于整个师中。当编制变化时，新加入的部队（新兵）会拉低平均值，而裁撤的部队（老兵）则会保留经验值，从而提升剩余部分的平均值**[citation:7]。

#### 1. 基础训练流程

*   **训练新兵**：在招募与部署界面训练新部队。当训练进度达到**20%**后，可以选择“提前部署”，此时部队为**“新兵”**（绿色，-25%战斗力）；若训练至**100%**再部署，部队为**“训练有素”**（无增减）[citation:2][citation:6]。
*   **演习提升**：将已部署的部队拉到地图上，命令其进行**“演习”**。演习会消耗装备（有6%的额外损耗），并缓慢积累经验，直到提升至**“正规”**（+25%战斗力）为止[citation:2][citation:4][citation:6]。此后，只有实战才能继续提升经验[citation:6]。
*   **节省装备**：如果装备紧张，可以在师团设计中，将训练用师的装备优先级设为**“老装备”**，让演习部队消耗库存的旧枪旧炮，把新装备留给一线部队[citation:4]。

#### 2. 切换编制保留/提升经验的技巧

| 操作 | 效果 | 说明与技巧 |
| :--- | :--- | :--- |
| **减少编制（缩编）** | **提升经验** | 当你把一个10步兵营的师缩编为9步兵营时，系统会优先裁撤经验最低的士兵，留下来的老兵比例更高，**全师的平均经验会因此提升**[citation:7]。这是“浓缩精华”的核心技巧。 |
| **增加编制（扩编）** | **稀释经验** | 当你给一个精锐师增加新的营时，新加入的士兵（新兵）没有经验，会**显著拉低全师的平均经验**[citation:6][citation:7]。这是要尽量避免的操作。 |
| **改动支援连** | **轻微影响** | 支援连的变动对经验影响较小，但同样遵循上述逻辑。 |
| **合并部队** | **谨慎操作** | 游戏1.5版本后增加了“合并”按钮，可以将两个缺编的相同模板部队合并。但合并后的部队经验会取平均值，不建议将高经验部队与低经验部队合并[citation:10]。 |

**进阶技巧：批量制造精锐**

利用上述原理，可以设计一个“批量制造精锐”的流程：
1.  **建立“培训”模板**：创建一个**大幅超编**的师团（例如20步兵营），命名为“基础训练师”。
2.  **大规模训练**：批量训练这些超编师，直到它们全部达到“训练有素”甚至“正规”水平。
3.  **一次性缩编**：在开战前夕，将所有“基础训练师”的模板**统一修改为正常作战编制**（例如9步兵营）。此时，每个师都会因为缩编而**经验值大幅跃升**，直接获得一批经验值极高的精锐部队。
4.  **回收装备**：缩编后多出来的装备会返还库存，可以用来装备新部队。

这个方法可以让你在战前快速、低成本地打造出一支精锐的“种子部队”，在战争初期形成局部优势。

### 💡 核心提示
*   **战地医院**：在精锐师的支援连中加入**战地医院**，可以减少战斗伤亡造成的经验损失，并让部分伤愈士兵（“回流” manpower）带着他们的经验返回部队[citation:6]。
*   **优先级设置**：在师团设计界面，可以将你的精锐师设为**“精锐”优先级**，这样在补充装备时，它们会优先拿到最新的武器[citation:5]。
