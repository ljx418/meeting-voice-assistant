### ⚙️ 方法一：使用「合并计算」或多重区域数据透视表（推荐：一次性查看汇总）
这个方法适合你想把多个工作表中同一个中心的数据“合并”在一起，看看总数或进行对比分析。它的核心是使用数据透视表（选择“多重合并计算区域”），可以把结构相同（比如都有“中心名称”、“销售额”这类列）的表格快速整合[citation:7]。

**操作步骤如下：**

1.  **启动向导**：按快捷键 `Alt + D + P`，调出“数据透视表和数据透视图向导”。
2.  **选择区域**：在向导中，选择 **“多重合并计算区域”**，然后点击“下一步”。
3.  **添加范围**：依次选择每个要合并的工作表数据区域，点击“添加”。
4.  **完成创建**：选择数据透视表放置的位置，点击“完成”。
5.  **执行筛选**：在新生成的数据透视表中，将“中心名称”字段拖到“筛选器”区域，就能在生成的透视表里筛选你想要的中心了。

### ✨ 方法二：使用 Power Query (适用于Excel 2016及更高版本)
如果你的Excel版本支持Power Query，它会是个更强大的选择。这个方法尤其适合数据量大、需要反复更新筛选的场景[citation:3][citation:7]。

**具体流程如下：**

1.  **导入数据**：点击“数据” -> “获取数据” -> “从文件” -> “从工作簿”，选择你的文件。在导航器中勾选需要合并的多个工作表，点击“转换数据”。
2.  **追加查询**：在Power Query编辑器中，确保各表列名一致。点击“主页” -> “追加查询”，将所有表的数据整合为一个。
3.  **筛选数据**：在合并后的数据列中，直接使用筛选按钮，只保留你需要的那个中心的数据。
4.  **加载结果**：点击“关闭并上载”，筛选结果就会加载到一个新的工作表中。以后原始数据更新，只需右键这个结果表，选择“刷新”即可自动更新。

### ✍️ 方法三：编写VBA宏 (适合需要自动化、重复操作)
如果你需要经常执行这个操作，或者想实现更复杂的数据处理逻辑，可以编写一个简单的VBA宏来自动化这个过程[citation:3][citation:5]。

```vba
Sub FilterAcrossSheets()
    Dim ws As Worksheet
    Dim targetValue As String
    ' 在对话框中输入你想筛选的中心名称
    targetValue = InputBox(“请输入要筛选的中心名称：”)
    
    ' 如果没有输入内容，则退出宏
    If targetValue = “” Then Exit Sub
    
    ' 遍历工作簿中的每一个工作表
    For Each ws In ThisWorkbook.Worksheets
        With ws
            ' 确保工作表可见
            .Visible = xlSheetVisible
            ' 启用自动筛选模式
            .AutoFilterMode = False
            ' 假设“中心名称”在A列，则使用第1列进行筛选
            ' 如果你的“中心名称”在其他列，请修改Range(“A1”)中的列号
            .Range(“A1”).AutoFilter Field:=1, Criteria1:=targetValue
        End With
    Next ws
End Sub
```

> 使用VBA前，记得将文件保存为 **.xlsm** (启用宏的工作簿) 格式。

## ✅ 方案一：每个工作表单独保存为一个新文件

适合你希望**按中心拆分文件**，例如：  
`北京中心.xlsx`、`上海中心.xlsx`

```vba
Sub FilterAndSaveEachSheetToNewFile()
    Dim ws As Worksheet
    Dim targetValue As String
    Dim newWb As Workbook
    Dim rng As Range
    
    ' 输入要筛选的中心
    targetValue = InputBox("请输入要筛选的中心名称：")
    If targetValue = "" Then Exit Sub
    
    ' 关闭屏幕闪烁，加快速度
    Application.ScreenUpdating = False
    
    ' 遍历所有工作表
    For Each ws In ThisWorkbook.Worksheets
        ws.AutoFilterMode = False
        
        ' 假设“中心名称”在第1列（A列），请根据实际情况修改
        With ws
            .Range("A1").AutoFilter Field:=1, Criteria1:=targetValue
            
            ' 判断筛选后是否有可见数据（排除标题行）
            Set rng = .AutoFilter.Range.Offset(1, 0).Resize(.AutoFilter.Range.Rows.Count - 1, .AutoFilter.Range.Columns.Count)
            On Error Resume Next
            Set rng = rng.SpecialCells(xlCellTypeVisible)
            On Error GoTo 0
            
            If Not rng Is Nothing Then
                ' 复制筛选结果到新工作簿
                Set newWb = Workbooks.Add
                .AutoFilter.Range.Copy
                newWb.Sheets(1).Range("A1").PasteSpecial Paste:=xlPasteAll
                Application.CutCopyMode = False
                
                ' 保存新文件（路径为当前文件所在目录 + 中心名称 + 工作表名）
                newWb.SaveAs ThisWorkbook.Path & "\" & targetValue & "_" & ws.Name & ".xlsx"
                newWb.Close SaveChanges:=False
            End If
        End With
        
        ws.AutoFilterMode = False
    Next ws
    
    Application.ScreenUpdating = True
    MsgBox "已完成！文件保存在：" & ThisWorkbook.Path
End Sub
```

## ✅ 方案二：所有筛选结果放到同一个新文件的多个工作表

更常见：一个 Excel 文件里，每个工作表对应原工作表的筛选结果。

```vba
Sub FilterAndSaveToOneFile()
    Dim ws As Worksheet
    Dim targetValue As String
    Dim newWb As Workbook
    Dim newSheet As Worksheet
    
    targetValue = InputBox("请输入要筛选的中心名称：")
    If targetValue = "" Then Exit Sub
    
    Application.ScreenUpdating = False
    
    ' 创建新工作簿
    Set newWb = Workbooks.Add
    ' 删除默认多余的空白表（保留一个用于复制）
    Do While newWb.Sheets.Count > 1
        Application.DisplayAlerts = False
        newWb.Sheets(newWb.Sheets.Count).Delete
        Application.DisplayAlerts = True
    Loop
    
    For Each ws In ThisWorkbook.Worksheets
        ws.AutoFilterMode = False
        
        ' 同样假设中心名称在第1列
        With ws
            .Range("A1").AutoFilter Field:=1, Criteria1:=targetValue
            
            ' 检查是否有数据
            Dim visRng As Range
            Set visRng = .AutoFilter.Range
            On Error Resume Next
            Set visRng = .AutoFilter.Range.SpecialCells(xlCellTypeVisible)
            On Error GoTo 0
            
            If Not visRng Is Nothing Then
                ' 添加新工作表（名称 = 原工作表名）
                Set newSheet = newWb.Sheets.Add(After:=newWb.Sheets(newWb.Sheets.Count))
                newSheet.Name = ws.Name
                
                ' 复制筛选结果
                .AutoFilter.Range.Copy
                newSheet.Range("A1").PasteSpecial Paste:=xlPasteAll
                Application.CutCopyMode = False
            End If
        End With
        
        ws.AutoFilterMode = False
    Next ws
    
    ' 删除第一个空表
    Application.DisplayAlerts = False
    newWb.Sheets(1).Delete
    Application.DisplayAlerts = True
    
    ' 保存文件
    newWb.SaveAs ThisWorkbook.Path & "\" & targetValue & "_合并结果.xlsx"
    newWb.Close SaveChanges:=False
    
    Application.ScreenUpdating = True
    MsgBox "已保存至：" & ThisWorkbook.Path
End Sub
```

## ⚠️ 使用前注意

1. **列位置要确认**  
   代码里写的是 `Field:=1`（第1列 A列），如果你的“中心名称”在 B 列，就改成 `Field:=2`。

2. **第一行是标题**  
   默认第一行是表头，会被一并复制过去。

3. **保存路径**  
   新文件会保存在当前工作簿所在的文件夹。  
   如果想换路径，修改这一行：  
   `ThisWorkbook.Path & "\"` → `"C:\你的路径\"`

4. **文件格式**  
   我用了 `.xlsx`（不支持宏），如果需要保留宏请改成 `.xlsm`。
