下面我会详细说明这两种方法，并补充安装后关键的配置步骤，让你的股市观察者能顺利运行起来。

### **第一步：选择并安装你的Skill**

你可以根据具体需求，从下面两种方式中选择一种来操作。

#### **方法一：命令行一键安装（最推荐，最简单）**
这是安装标准Skill最快捷的方式，OpenClaw会自动从官方的“技能商店”（ClawHub）下载并处理所有依赖[citation:2][citation:9]。

*   **打开你的WSL终端**，输入以下命令来安装一个名为 `qveris-official`（这是我上次建议你安装的A股数据Skill）的技能：
    ```bash
    openclaw skills install qveris-official
    ```
    *   **命令解释**：`openclaw skills install` 是安装命令的标准格式[citation:2][citation:5]。系统会自动连接ClawHub仓库，下载技能文件并处理所需的依赖[citation:9]。
*   **验证安装**：安装完成后，可以输入以下命令查看所有已安装的技能列表，确认 `qveris-official` 是否在列表中：
    ```bash
    openclaw skills list
    ```

#### **方法二：手动挂载安装（适用于第三方或自研Skill）**
如果你从GitHub或其他社区下载了一个技能包，或者自己开发了一个技能，就需要用这种方式把它“手动”放到OpenClaw的“技能收纳箱”里[citation:4][citation:9]。

1.  **找到OpenClaw的技能目录**：在WSL的终端中，这个目录的默认路径通常是 `~/.openclaw/skills/`[citation:4][citation:9]。你可以用下面的命令直接打开它：
    ```bash
    cd ~/.openclaw/skills/
    ```
    或者在Windows文件管理器中，直接导航到 `\\wsl$\你的发行版名称\home\你的用户名\.openclaw\skills\`。

2.  **放入技能文件夹**：将你准备好的技能文件夹（例如，一个包含 `SKILL.md` 文件的文件夹[citation:4]）完整地复制到这个目录下。

### **第二步：安装后的关键配置与验证**

技能装好了，但它可能还需要一些“钥匙”才能正常工作，并且需要被“唤醒”。

#### **1. 配置环境变量（提供API密钥）**
像 `qveris-official` 这样的技能，需要你之前申请的API Key才能从数据源获取信息[citation:2][citation:6][citation:9]。你需要把这个Key作为环境变量告诉OpenClaw。

*   **编辑配置文件**：打开OpenClaw的全局配置文件，通常是 `~/.openclaw/config.yaml`[citation:9]。
    ```bash
    nano ~/.openclaw/config.yaml
    ```
*   **添加变量**：在配置文件中，按照特定格式添加你的API Key。例如，为 `qveris-official` 技能添加 `QVERIS_API_KEY`：
    ```yaml
    skills:
      - name: "qveris-official"
        enabled: true
        config:
          env:
            QVERIS_API_KEY: "你的QVeris_API密钥"
    ```
    *   **安全提示**：这个文件相当于技能的“保险柜”，OpenClaw运行时用户（如 `openclaw` 用户）通常无法修改它，只能读取，这能有效防止技能本身意外篡改配置[citation:6]。

#### **2. 重启服务并验证**
配置文件和技能文件就位后，需要重启OpenClaw的后台服务（网关），它才能重新加载所有配置和新技能[citation:6][citation:9]。

*   **重启服务**：在WSL终端中执行：
    ```bash
    openclaw gateway restart
    ```
*   **最终验证**：服务重启后，再次使用 `openclaw skills list` 命令，确保你的技能不仅存在，而且状态是“已启用”。你也可以直接向你的飞书机器人提问，比如“帮我查询一下今天的A股热点板块”，看看它是否能调用新技能来完成任务[citation:2][citation:5]。

至此，你就成功在Windows的WSL环境中为OpenClaw安装了新的Skill，并完成了使其能够工作的关键配置。接下来，就可以去完善你的股市观察者Agent了。
