苹果账户被锁定，通常是苹果为了保护你的账户安全而采取的一种自动措施。当系统检测到可能威胁账户安全的异常活动时，就会暂时锁定账户，防止未经授权的访问[citation:1][citation:2][citation:3]。

以下是导致账户被锁定的几个主要原因：

| 锁定原因 | 具体说明 |
| :--- | :--- |
| **🔐 密码或信息错误次数过多** | 这是最常见的原因。如果**你或其他人**在短时间内多次输入错误的密码、安全问题的答案或其他账户信息，系统会认为这可能是一次攻击，从而自动锁定账户[citation:1][citation:3][citation:8]。 |
| **💳 账户与付款问题** | 如果你的Apple ID关联了过期的信用卡、有未支付的订单或订阅费用未处理成功，苹果可能会因此停用你的账户[citation:4][citation:5]。 |
| **⚠️ 可疑的登录活动** | 系统检测到你的账户有异常登录行为。例如，从一个从未登录过的新设备或新的地理位置尝试登录，或者有短时间内大量登录的异常行为[citation:4][citation:7]。 |
| **🛠️ 使用第三方软件** | 使用非官方的、未经授权的第三方软件（如一些iCloud数据访问工具）来访问你的账户，可能会触发苹果的安全机制，导致账户被锁定[citation:6][citation:9]。 |
| **📱 账户信息不匹配** | 在极少数情况下，如果你购买的二手设备还绑定着原机主的Apple ID，或者在“设置”和“App Store”中登录了不同的账户，也可能引发账户权限错误，提示被停用[citation:5][citation:7]。 |

看到账户被锁定的提示先别着急，通常情况下，你可以通过以下步骤自行解决。不过请注意，**千万不要重复尝试错误密码，这可能会延长锁定时长**[citation:5]。

### 如何解锁你的账户？

**第一步：通过官方渠道重置密码（首选方法）**

绝大多数账户锁定都可以通过**重置密码**来解锁。

1.  **访问官方平台**：在浏览器中访问 [`iforgot.apple.com`](https://iforgot.apple.com) 或在你的设备上打开“设置”App。
2.  **输入账户信息**：按照屏幕提示，输入你被锁定的Apple ID（通常是你的邮箱或手机号）。
3.  **验证身份**：选择通过注册邮箱、受信任的手机号（接收短信或电话）或回答安全问题来重置密码[citation:4][citation:6]。
4.  **设置新密码**：验证成功后，创建一个新密码，之后就可以用新密码正常登录了。

**第二步：如果自助重置失败**

有时你可能会收到“此Apple ID已锁定，无法使用”的提示，或者自助服务无法验证你的身份。这通常意味着你需要苹果官方客服的帮助。

-   **请求访问权限**：在登录界面直接点击提示中的“**请求访问权限**”或“**要求取用权限**”按钮，按照指引提交申请[citation:1][citation:2][citation:3]。
-   **联系官方支持**：如果以上方法都无效，可以直接联系Apple支持。你可以在苹果官网预约回电，或拨打官方客服电话。在联系前，最好准备好你的Apple ID、任何能证明你是账户持有人的信息（如注册时收到的邮件、购买凭证等）[citation:6][citation:7]。

为了避免未来再次遇到类似情况，建议你：
-   **开启双重认证**，为账户增加一道安全保障。
-   **保持付款信息有效**，及时更新过期的信用卡。
-   **只通过苹果官方渠道**登录和管理你的账户[citation:9]。

在 Mac（或任何 Unix/Linux 系统）上执行 `.sh` 脚本很简单。常用的方法有以下几种：

### 1. 先给脚本添加执行权限（通常需要这一步）

打开终端，进入脚本所在目录，运行：

```bash
chmod +x 你的脚本名字.sh
```

这会让脚本变成可执行文件。

### 2. 执行脚本

添加权限后，可以用下面任一方式执行：

- **直接运行（最常用）**  
  ```bash
  ./你的脚本名字.sh
  ```
  注意前面的 `./` 表示当前目录。如果脚本在 `$PATH` 路径下（比如 `/usr/local/bin`），可以省略 `./`。

- **用 sh 命令执行（不需要提前加执行权限）**  
  ```bash
  sh 你的脚本名字.sh
  ```

- **用 bash 执行（如果脚本用的是 bash 语法）**  
  ```bash
  bash 你的脚本名字.sh
  ```

### 3. 如果不想加权限，也可以用 `source` 或 `.` 执行

这会让脚本在当前 shell 进程中运行（而不是新开子进程），通常用于设置环境变量：

```bash
source 你的脚本名字.sh
# 或者
. 你的脚本名字.sh
```

### 4. 举个完整的例子

假设你在桌面有一个 `test.sh` 文件，内容如下：

```bash
#!/bin/bash
echo "Hello, World!"
```

在终端中：

```bash
cd ~/Desktop
chmod +x test.sh
./test.sh
```

就会输出 `Hello, World!`。

- 如果执行时提示 `Permission denied`，说明忘了加执行权限。
- 脚本第一行通常写 `#!/bin/bash` 或 `#!/bin/sh`，指定解释器。
- 如果脚本里用了相对路径（比如 `../file`），建议先 `cd` 到脚本所在目录再执行，或者使用绝对路径。

### 🧱 核心概念
Tmux 采用三层结构来组织你的工作空间[reference:3][reference:4]：

| 概念 | 说明 |
| :--- | :--- |
| **会话(Session)** | 最顶层的独立工作区，可包含多个窗口。即使断开连接，会话也会在后台运行。 |
| **窗口(Window)** | 会话中的标签页，每个窗口占据整个终端屏幕。 |
| **窗格(Pane)** | 窗口内的子区域，允许你并排显示多个终端。 |

所有操作都通过一个 **前缀键** 触发，默认是 `Ctrl + b`[reference:5]。你需要先按下 `Ctrl + b`（释放），再按其他功能键。

### 🚀 常用命令与快捷键

#### 会话管理

| :--- | :--- |
| **创建新会话** | `tmux new -s <会话名>` |

| **列出所有会话** | `tmux ls` |
| **重新连接会话** | `tmux attach -t <会话名>`[reference:7] |
| **切换会话** | 快捷键：`prefix` + `s`[reference:8] |
| **杀死会话** | `tmux kill-session -t <会话名>`[reference:9] |
