### 🎮 常用功能测试实例

下面以最常见的测试场景为例，分别展示如何使用 **Hypium** 和 **hmdriver2** 编写测试脚本。

#### 1. 点击、滑动等基础UI操作
这是最常见的测试，例如模拟用户点击某个按钮，或进行滑动操作。

**使用 Hypium 示例**
```python
from devicetest.core.test_case import TestCase
from hypium import UiDriver, By, Gesture, Point

class TC_001(TestCase):
    def __init__(self, controllers):
        super().__init__(self.__class__.__name__, controllers)
        # 初始化 UiDriver，self.device1 代表连接的第一个设备
        self.driver = UiDriver(self.device1)

    def setup(self):
        # 1. 点击操作：查找文本为"设置"的控件并点击
        self.driver.find_element(By.text("设置")).click()
        
        # 2. 滑动操作：从 (500, 1500) 滑动到 (500, 500)，时长 500ms
        self.driver.swipe(500, 1500, 500, 500, duration=500)

        # 3. 手势操作：连续滑动 (例如画个"Z"字形)
        gesture = Gesture()
        gesture.start(Point(100, 500).to_tuple(), 0.5) # 起始点，长按0.5秒
        gesture.move_to(Point(300, 500).to_tuple())    # 向右滑动
        gesture.pause(0.5)                             # 停留0.5秒
        gesture.move_to(Point(100, 700).to_tuple())    # 向左下滑动
        self.driver.inject_gesture(gesture)            # 执行手势[reference:15]

    def test(self):
        # 在这里编写你的主要测试逻辑
        pass
```

**使用 hmdriver2 示例**
```python
from hmdriver2.driver import Driver

# 1. 连接设备，序列号可通过 `hdc list targets` 命令获取
d = Driver("你的设备序列号")

# 2. 启动应用 (以日历应用为例)
d.start_app("com.huawei.calendar", "com.huawei.calendar.MainActivity")

# 3. 点击操作：查找文本为"新建"的控件并点击
d(text="新建").click()

# 4. 滑动操作：从屏幕中央向上滑动
d.swipe(0.5, 0.8, 0.5, 0.2) # hmdriver2 支持比例坐标 (0-1)

# 5. 输入文本
d(resource_id="search_input").set_text("Hello HarmonyOS")

# 6. 截图
d.screenshot("screenshot.png")
```

#### 2. 复杂的页面跳转流程测试
模拟用户执行一系列操作，验证页面能否正确跳转。

**使用 Hypium 示例（参考官方案例）**
以下代码模拟了点击“我的”页面中的多个菜单项，并验证页面跳转的正确性[reference:16][reference:17]。
```python
from devicetest.core.test_case import TestCase
from hypium import UiDriver, By

class TC_002(TestCase):
    def test_my_page_navigation(self):
        driver = UiDriver(self.device1)

        # 假设我们已经处于"我的"页面
        # 点击"我的账号信息"
        driver.find_element(By.text("我的账号信息")).click()
        # 验证是否跳转到账号信息页
        assert driver.find_element(By.text("账号管理")).exists()

        # 返回上一页
        driver.go_back()

        # 点击"我的地址"
        driver.find_element(By.text("我的地址")).click()
        assert driver.find_element(By.text("新增地址")).exists()

        driver.go_back()

        # 点击"我的订单"
        driver.find_element(By.text("我的订单")).click()
        assert driver.find_element(By.text("全部订单")).exists()

        driver.go_back()
```

### 💡 故障排查

在实践过程中，你可能会遇到一些小问题，这里提供几个常见的解决方法：
*   **设备无法识别**：请检查 `hdc` 是否安装正确，可通过 `hdc list targets` 查看已连接设备。
*   **点击无效/定位失败**：元素可能还未加载完成，请在操作前使用 `driver.wait_element_exists(By.text("目标文本"), timeout=5000)` 等显式等待方法。
*   **权限问题**：确保手机端的“开发者模式”和“USB调试”已开启，并授权电脑进行调试。
